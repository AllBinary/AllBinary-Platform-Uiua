                             AllBinary Platform Uiua

What is it?

This repository contains code generated by the AllBinary Platform for support in Uiua.  
This repo is used to allow developers to skip the Uiua code generation step.

What are some example games with this Uiua code?

https://allbinary.itch.io (The downloads with "-uiua" in the filename are Uiua only builds. Currently that only includes nothing. Also the Uiua builds are not available on Google Play or other stores.)
